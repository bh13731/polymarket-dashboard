Methodology

This study follows the bedrock principles documented in docs/research/ml-methodology.md:

  1. Strict point-in-time feature construction.
  2. Walk-forward / rolling-origin nested CV (NEVER random K-fold; lint-enforced).
  3. 14-day held-out test window, locked at the start of the study, touched once.
  4. Cost-adjusted net Sharpe is the only ranking metric.
  5. BH-FDR multiple-comparison correction before any “beats baseline” claim.
  6. Every experiment reproducible from its registry row (git_sha + dataset_sha256 + seed + library versions).

The score module (polymarket_agent.research.score.score) is the only safe live entry point and is opt-in disabled by default.

Leakage diagnostics

The leakage battery in tests/research/test_no_leakage.py asserts each of the eight bedrock anti-patterns:

  1. Future feature leak (asof-fuzz parametrised over every feature).
  2. Target encoding leak (no fold-shared categorical encoders).
  3. Train/test contamination by candidate key.
  4. Lookahead in volatility windows (target bar excluded).
  5. Survivorship: every market alive at evaluation time.
  6. Cost-zero shortcut: net-PnL never reported without slippage subtracted.
  7. Multiple-test illusion: BH-FDR before any “beats baseline” claim.
  8. Reverse-causality feature names.

Static lint find_random_kfold_violations sweeps the entire research subtree and is asserted clean by every focused test module.
